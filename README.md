# TutorCRM Telegram Bot (Микро-CRM для репетиторов)

Многопользовательский Telegram-бот для репетиторов, автоматизирующий ведение учеников, расписание занятий, темы/ДЗ, учет абонементов и финансов с экспортом в Excel и утренними дайджестами.

## 🚀 Возможности
- **Мультипользовательская архитектура**: любой репетитор может запустить бота (`/start`) и получить свой изолированный кабинет.
- **Ученики**: добавление карточек учеников, фиксация предметов, контактов, ставок и заметок по целям обучения.
- **Гибкая тарификация**: 
  - Поурочная оплата (рублевый баланс, уход в минус при долге).
  - Абонементы / пакеты уроков (счетчик оставшихся оплаченных занятий).
- **Повторяющееся расписание + разовые уроки**:
  - Настройка регулярных слотов (например, *Пн 17:00*, *Чт 18:30*) с автогенерацией на 14 дней вперед.
  - Назначение внеплановых / разовых занятий на любую дату и время.
- **Управление уроками**:
  - Отметка статуса: «Проведен» (с автоматическим списанием средств/урока) или «Отменен».
  - Перенос урока на другое время/день в пару кликов.
  - Запись **Темы урока** и **Домашнего задания**.
- **Экспорт в Excel**:
  - Выгрузка всей базы в один клик: карточки учеников, история уроков, история платежей и балансы в красивой таблице `.xlsx`.
- **Утренний дайджест (APScheduler)**:
  - Автоматическая рассылка плана уроков на текущий день каждое утро в 08:00 (можно включить/выключить в настройках).
- **Финансы и дашборд**: учет платежей, сводка доходов за месяц, подсчет проведенных уроков и список должников.

## 🛠 Установка и запуск

### 1. Получение токена бота
1. Перейдите в Telegram к официальному боту [@BotFather](https://t.me/botfather).
2. Отправьте команду `/newbot` и следуйте подсказкам:
   - Введите имя бота (например: `Мой Репетитор CRM`).
   - Введите уникальный юзернейм, заканчивающийся на `_bot` (например: `tutor_master_crm_bot`).
3. Скопируйте полученный API токен.

### 2. Настройка файла окружения `.env`
В папке проекта `tutor_crm_bot` создайте файл `.env` (на основе `.env.example`):
```ini
BOT_TOKEN=ВАШ_ТОКЕН_ОТ_BOTFATHER
DATABASE_URL=sqlite+aiosqlite:///tutor_crm.db
```

### 3. Запуск бота
Запустите бота командой в терминале:
```bash
python bot.py
```

После этого откройте вашего бота в Telegram и отправьте команду `/start`!
